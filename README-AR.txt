MEROUANE MOTOCYCLE PRO - النسخة السحابية متعددة المستخدمين

هذه النسخة تصلح مشكلة ظهور الشعار في شاشة الدخول، وتدعم:
- مدير المحل + حسابات البائعين.
- نفس المخزون والمبيعات والفواتير على عدة هواتف.
- مزامنة فورية للمخزون والمبيعات.
- إرجاع الفاتورة وتصحيح المخزون للجميع.
- مشاهدة وطباعة الفاتورة.
- المدير يستطيع تفعيل/تعطيل حسابات البائعين.
- ترقيم فواتير آمن عند البيع من أكثر من هاتف في نفس الوقت.

الإعداد:
1) مشروع Supabase موجود بالفعل؟ ممتاز. لا تعيد تشغيل multi_schema.sql إذا كنت نفذته سابقاً.
2) افتح SQL Editor وشغّل الملف: supabase_patch.sql
3) من Supabase > Connect أو Settings > API Keys خذ:
   - Project URL
   - Publishable Key (يبدأ عادةً بـ sb_publishable_)
4) افتح التطبيق. إذا ظهرت شاشة إعداد الاتصال، ضع Project URL في Supabase URL وPublishable Key في الحقل المخصص له.
5) في أول هاتف: حساب جديد > إنشاء الحساب كمدير. اكتب اسم المحل ورمز المحل، مثل MEROUANE01.
6) في هاتف البائع: حساب جديد > الانضمام إلى محل — بائع، ثم أدخل نفس رمز المحل.
7) من المزيد > المستخدمون يستطيع المدير مشاهدة البائعين وتفعيل/تعطيل حساباتهم.

مهم:
- لا تستخدم Secret Key أو service_role داخل التطبيق ولا ترسلها لأي شخص.
- Publishable Key هي المفتاح المخصص لتطبيق المتصفح/الهاتف، مع بقاء حماية RLS مفعلة.
- إذا كان تأكيد البريد الإلكتروني مفعلاً في Supabase، أكّد البريد ثم سجّل الدخول من نفس الهاتف؛ التطبيق سيكمل ربط الحساب بالمحل تلقائياً.
- التطبيق يحتاج الإنترنت حتى تتزامن البيانات بين الهواتف.
